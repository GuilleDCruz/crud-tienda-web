# 001 - Project Decisions

## Language
- Backend: Java 21
- Frontend: Angular
- Database: PostgreSQL

## Backend Framework
- Spring Boot

## Build Tool
- Maven

## Package Convention
- Base package: com.guilledev.backend

## Coding Language
- Source code, packages, classes, methods, variables and commits will be written in English.
- User-facing text may be in Spanish.

## Development Principles
- Incremental development.
- Small and descriptive commits.
- Documentation is written alongside implementation.
- Project organized by feature rather than by technical layer.
